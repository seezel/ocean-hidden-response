## User journey

- Immediately show product title, a short specific explanation of satellite surface chlorophyll (a pigment-based indicator, not total biomass) and SST, and the main working chart. No invented scientific conclusion before real observations load.
- Controls: chlorophyll/SST, both regions/EEP/NWP, start and end month inputs restricted to available records, Apply dates button, Restore reference button. Reference investigation visibly distinguished from exploratory custom window. Invalid or insufficient windows may show observed data, never previous statistics.
- Main SVG chart, drawn in native vanilla JS with no libraries/CDNs. Monthly lines have missing-data gaps; trend line visibly different. Both regions are labelled and differentiated by pattern as well as color. Accessible SVG title/description, readable axes, visible units, human-readable chart text summary. Tooltip/inspection if implemented must work on focus/tap, not hover only. An equivalent expandable observation table makes numerical observations available to keyboard/screen-reader users. Do not create hundreds of tab stops in the SVG.
- Compact trend table per selected region: rate/decade,95% CI, valid months,p-value with honest uncertainty wording. Chlorophyll includes absolute concentration context and baseline-anchored mg/m3 per decade change labelled with its baseline. SST never percentage. A direct chlorophyll regional contrast section shows comparison direction, uncertainty and whether evidence is inconclusive, explicitly describing relative/log-scale difference, not absolute mg/m3 slope difference. Different individual p-values are not a regional test.
- Supporting Pacific locator with EEP and NWP exact bounds; code-native SVG schematic longitude/latitude reference is fine, clearly marked schematic if no authoritative coastline asset. Do not draw pretend geographic coastlines. The map is supporting, not primary.
- Expandable plain-language/technical methods, data quality/coverage, source provenance and limitations. Show exact product/version, observed months, source refresh versus real-time distinction, HAC approximate uncertainty and exploratory-window caveat. Never claim causation.
- A NASA verification record can show the authentic monthly MODIS source and two regional averages when primary exports provide them; one month cannot verify trend agreement. Show blocked/unavailable status without fake values otherwise.
- Actual download links will be ./downloads/observations.csv and ./downloads/reproduction.zip; source package/readme are included there by main. Avoid unimplemented links. Product has no analytics/accounts/signup.
- Loading, empty, and recoverable error state. If fetch fails, no fake/synthetic production data; show Retry button. Use textContent/DOM construction for provider metadata, not unsafe innerHTML.
